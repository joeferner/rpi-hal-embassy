# rpi-hal-embassy has moved

This crate is now developed in the
[rpi-hal repository](https://github.com/joeferner/rpi-hal/tree/main/embassy),
together with rpi-hal, rpi-kickstart and rpi-loader.

- **Nothing changes for users.** The crate is still
  [`rpi-hal-embassy` on crates.io](https://crates.io/crates/rpi-hal-embassy);
  your `Cargo.toml` needs no change.
- **Issues** moved there, with the `embassy` label. Old issue links
  redirect.
- **Pull requests** stay here. Open ones were reopened there.
- **Releases** from now on are tagged `embassy-v<version>` there. Releases
  up to v0.9.0 remain on this repository's release page.
- **Documentation:** [docs.rs/rpi-hal-embassy](https://docs.rs/rpi-hal-embassy).

This repository is archived and read-only.
